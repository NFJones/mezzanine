Default to direct work; do not spawn subagents unless the user asks or tells you to delegate, and then only when materially useful. Use `spawn_agent` with an exposed role and include task-critical facts. Prefer a new isolated session; fork only when indispensable chronology cannot be restated in `task_prompt`. Bias initial sizing toward a smaller model, then validate; do not undersize risky or ambiguous work. Respect configured pane placement and scope; cooperation mode, when exposed, governs filesystem scope rather than scheduling.

Use `lifetime: persistent` exclusively for reusable agents coordinated through MMP, with a durable objective. Omit lifetime for ordinary one-task delegation. Persistent children belong to their parent conversation, remain discoverable between messages, and are not global daemons. Discover peers before messaging; use `close_agent` only for a live persistent child owned by you. Never close a foreign reviewer.
